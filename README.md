# 🏦 LMH Bank — Telegram-бот онлайн-банкинга

Демонстрационный Telegram-бот для онлайн-банкинга на **Python + aiogram 3** с
хранением данных в **SQLite**. Пользователь получает виртуальный счёт и карту,
может смотреть баланс, пополнять и снимать средства, переводить деньги другим
пользователям бота, выпускать карты и просматривать историю операций.

> ⚠️ **Внимание:** это учебный/демонстрационный проект. Все счета, карты и
> деньги виртуальные. Бот не подключается к реальным банковским системам и не
> предназначен для обработки настоящих платежей.

## Возможности

- 💰 **Баланс** — текущий остаток по счёту
- 📥 **Пополнение** и 📤 **снятие** средств (симуляция)
- 💸 **Переводы** между счетами пользователей по 20-значному номеру, с подтверждением
- 💳 **Виртуальные карты** — номер по алгоритму Луна, срок действия, держатель (до 3 карт)
- 📜 **История операций** — последние 10 транзакций
- ⚙️ **Профиль** — данные пользователя и счёта
- Удобное меню на инлайн-кнопках + команды `/start`, `/menu`, `/balance`, `/history`, `/cards`, `/help`

## Технологии

- [aiogram 3](https://docs.aiogram.dev/) — асинхронный фреймворк для Telegram Bot API
- [aiosqlite](https://github.com/omnilib/aiosqlite) — асинхронный SQLite
- Хранение денег в **копейках** (целые числа) — без ошибок округления
- Атомарные переводы в рамках одной транзакции БД (`BEGIN`/`COMMIT`/`ROLLBACK`)

```
bot/

├── config.py           # чтение настроек из .env

    └── operations.py   # пополнение, снятие, перевод (FSM)
run.py                  # удобный запуск: python run.py
```

## Быстрый старт

1. Получите токен у [@BotFather](https://t.me/BotFather) в Telegram.

2. Установите зависимости:

   ```bash
   python -m venv .venv
   source .venv/bin/activate      # Windows: .venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. Создайте файл `.env` на основе примера и впишите свой токен:

   ```bash
   cp .env.example .env
   # откройте .env и укажите BOT_TOKEN=<ваш токен>
   ```

4. Запустите бота:

   ```bash
   python run.py
   ```

5. Откройте бота в Telegram и отправьте `/start`.

## Переменные окружения (`.env`)

| Переменная  | Описание                                            | По умолчанию    |
|-------------|-----------------------------------------------------|-----------------|
| `BOT_TOKEN` | Токен бота от @BotFather (**обязательно**)          | —               |
| `DB_PATH`   | Путь к файлу базы данных SQLite                      | `data/bank.db`  |
| `ADMIN_IDS` | ID администраторов через запятую (зарезервировано)  | пусто           |

## Безопасность

- Токен бота хранится только в `.env`, который добавлен в `.gitignore` и **не
  попадает в репозиторий**. Никогда не коммитьте реальный токен.
- Если токен всё же был скомпрометирован — отзовите его командой `/revoke` у
  @BotFather и получите новый.
- Файл базы данных (`*.db`, `data/`) также исключён из репозитория.

## Как проверить перевод между двумя людьми

1. Пользователь A отправляет `/start` — получает счёт и карту.
2. Пользователь A пополняет счёт через 📥 **Пополнить**.
3. Пользователь B отправляет `/start` и копирует номер своего счёта из 💰 **Баланс**.
4. Пользователь A выбирает 💸 **Перевод**, вводит номер счёта B и сумму, подтверждает.
5. Оба видят операцию в 📜 **Истории**.
